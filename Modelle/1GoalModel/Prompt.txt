Create a **Goal and Problem Model according to 4EM** for the given case.

## Purpose of the model

The Goal and Problem Model describes **what the enterprise or its stakeholders want to achieve or avoid**.  
It shows goals, problems, threats, weaknesses, opportunities, and constraints.  
It also explains why certain processes, rules, or requirements exist and which problems hinder the achievement of goals.

## Allowed elements

Use only the following element types:

- Goal
- Problem
- Threat
- Weakness
- Opportunity
- Constraint

## Allowed connections

Use only the following connection types:

- supports
- conflicts
- hinders
- AND_decomposition
- OR_decomposition

## Possible connections between elements

- Goal supports Goal
- Goal conflicts Goal
- Problem hinders Goal
- Threat hinders Goal
- Weakness hinders Goal
- Opportunity supports Goal
- Constraint supports Goal
- Constraint conflicts Goal
- Constraint hinders Goal
- Goal AND_decomposition Goal
- Goal OR_decomposition Goal

## Output format

Output the model **only** in the following format:

ELEMENTS
ElementType <name_1>
ElementType <name_2>
…
ElementType <name_n>

CONNECTIONS
<element name> supports <element name>
<element name> conflicts <element name>
<element name> hinders <element name>
<element name_1> <element name_2> <element name_3> … <element name_n> AND_decomposition <element name>
<element name_1> <element name_2> <element name_3> … <element name_n> OR_decomposition <element name>

You can use as many Elements and Connections as you want. You can only use components that are specified in ELEMENTS for defining Connections.  
Do not write explanations, descriptions, bullet points, or additional text outside the ELEMENTS and CONNECTIONS sections.
