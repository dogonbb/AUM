Create a **Business Process Model according to 4EM** for the given case.

## Purpose of the model

The Business Process Model describes **how work is carried out in the enterprise**.  
It shows business processes, subprocesses, external processes, information sets, and material sets.  
It also explains how information and material move between processes and which inputs and outputs are used or produced.

## Allowed elements

Use only the following element types:

- Business Process
- Subprocess
- External Process
- Information Set
- Material Set

## Allowed connections

Use only the following connection types:

- information_flow
- material_flow
- uses
- produces
- part_of
- triggers
- supports
- refers_to

## Possible connections between elements

- Business Process information_flow Business Process
- Business Process information_flow External Process
- External Process information_flow Business Process
- Business Process material_flow Business Process
- Business Process material_flow External Process
- External Process material_flow Business Process
- Business Process uses Information Set
- Business Process uses Material Set
- Business Process produces Information Set
- Business Process produces Material Set
- Subprocess part_of Business Process
- Business Process triggers Business Process
- Business Process supports Goal
- Business Process refers_to Concept
- Information Set refers_to Concept
- Material Set refers_to Concept

## Output format

Output the model **only** in the following format:

ELEMENTS
ElementType <name_1>
ElementType <name_2>
…
ElementType <name_n>

CONNECTIONS
<element name> information_flow <element name>
<element name> material_flow <element name>
<element name> uses <element name>
<element name> produces <element name>
<element name_1>, <element name_2>, <element name_3> … part_of <element name>
<element name> triggers <element name>
<element name> supports <element name>
<element name> refers_to <element name>

You can use as many Elements and Connections as you want. You can only use components that are specified in ELEMENTS for defining Connections.  
Do not write explanations, descriptions, bullet points, or additional text outside the ELEMENTS and CONNECTIONS sections.
