Source model: Business Process Model

Allowed connectors (exact enumeration values):
- Input
- Output
- Triggers
- Supports
- uses
- creates
- motivates
- requires

Connector spelling and capitalization are case-sensitive.

Connector meanings (always source -> target):
- `Input`: the source receives or consumes the target as an input.
- `Output`: the source produces or supplies the target as an output.
- `Triggers`: the source initiates or causes the target to start or become active.
- `Supports`: the source positively contributes to the target without producing, consuming, or triggering it.
- `uses`: the source employs the target while being performed.
- `creates`: the source brings the target into existence.
- `motivates`: the source provides a reason or justification for the target.
- `requires`: the source depends on the target to be performed or completed.
