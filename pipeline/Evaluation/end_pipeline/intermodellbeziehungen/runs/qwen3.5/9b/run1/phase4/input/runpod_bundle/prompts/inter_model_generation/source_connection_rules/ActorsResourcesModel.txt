Source model: Actors and Resources Model

Allowed connectors (exact enumeration values):
- play
- is responsible for
- defines
- empty
- performs

`empty` means that a relationship exists but no more specific connector applies.
Connector spelling, spaces, and capitalization are significant.

Connector meanings (always source -> target):
- `play`: the source actor or organisational unit plays the target role.
- `is responsible for`: the source bears explicit responsibility for the target.
- `defines`: the source specifies or determines the target.
- `empty`: an explicit association exists but no specific allowed connector describes it; use only as a last resort.
- `performs`: the source carries out the target process or activity.
